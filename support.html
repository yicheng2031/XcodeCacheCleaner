刚开始用？几步就能开始清理。New to Xcode Cache Cleaner? Start in a few steps.

不用记命令，也不用到处找缓存目录。按下面几步，就能开始清理 Xcode 占用的空间。No commands to memorize and no cache folders to hunt down. Follow these steps to start clearing space used by Xcode.

开始使用Getting started

几步开始Start in a few steps

  1. 打开菜单栏应用Open the menu bar app

    下载并打开应用，它会安静地待在菜单栏里。Download and open the app. It stays quietly in your menu bar.

  2. 允许扫描Allow access

    如果你使用 Mac App Store 版本，打开应用菜单 → 关于 → 授权访问…，选择你的 ~/Library 文件夹。For the Mac App Store build, open the app menu → About → Grant Access… and choose your ~/Library folder.

  3. 扫描并选择Scan and choose

    应用会列出 Xcode、Simulator 和 Runtime 占用的空间。按分类开关，或展开列表选择具体项目。The app lists space used by Xcode, Simulator, and Runtimes. Toggle a category or expand a list to choose individual items.

  4. 点击清理Clean up

    点一下完成清理。熟悉后，还可以打开定时清理，让应用自动处理可重建的缓存和日志。Click once to clean up. When you are ready, enable scheduled cleanup for rebuildable caches and logs.

常见问题Frequently asked

为什么扫描不到内容？Why can’t I see any space?

通常是应用没有访问对应目录的权限。请先完成上面的 ~/Library 授权，然后重新检测；如果仍然失败，请在 Issue 中附上分类名称、macOS 版本和应用版本。The app usually lacks permission for the corresponding directory. Grant access to ~/Library, then scan again. If it still fails, include the category, macOS version, and app version in an issue.

Runtime 清理提示失败怎么办？What if Runtime cleanup shows an error?

Runtime 清理使用系统的 xcrun simctl 命令。删除过程中如果 Runtime 已经消失，或系统还在更新状态，命令仍可能返回错误，界面就会出现“删除失败”。这更常见于目标状态变化，不一定是超时。先重新扫描确认结果；只有 Runtime 仍在时，才需要再次尝试。Runtime cleanup uses the system xcrun simctl command. If the Runtime disappears during cleanup or the system is still updating its state, the command may return an error and the app can show “deletion failed.” This is more often a changing target state than a timeout. Scan again first, and retry only if the Runtime is still there.

清理后缓存又回来了？Why did the cache come back?

可重建缓存可能会在下一次编译、运行或打开预览时重新生成；这不是清理失败，而是 Xcode 的正常工作方式。Rebuildable caches may return when you compile, run, or open a preview again. That is normal Xcode behavior, not a cleanup failure.
